#  COVID-19 Data Cleaning & Analysis | Power BI

##  Project Overview

This project focuses on cleaning, transforming, and analyzing COVID-19 data using Microsoft Power BI. The analysis includes data preparation, missing value handling, calculated columns, data modeling, and country-wise trend analysis to generate meaningful insights.

##  Tools & Technologies

- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Transformation
- Data Modeling
- DAX
- Data Visualization

##  Dataset

The dataset contains COVID-19 information for different countries, including:

- Country
- Confirmed Cases
- Deaths
- Recovered Cases
- Active Cases
- Date

##  Data Cleaning & Transformation

- Imported and transformed COVID-19 datasets using Power Query.
- Removed duplicate records and handled missing values.
- Cleaned and standardized data for analysis.
- Created calculated columns for analytical reporting.
- Prepared the dataset for Power BI visualization.

##  Analysis Performed

- Analyzed country-wise COVID-19 trends.
- Compared confirmed, death, and recovery cases.
- Calculated Recovery Rate for analytical reporting.
- Created summarized tables for better analysis.
- Developed data models to support reporting.

##  Dashboard & Visualization

The project includes Power BI visualizations to present:

- Total Confirmed Cases
- Total Deaths
- Total Recovered Cases
- Recovery Rate
- Country-wise COVID-19 trends
- Overall COVID-19 performance
