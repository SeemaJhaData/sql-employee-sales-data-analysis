# Retail Data Analysis using Tableau

## Project Overview

This project focuses on analyzing retail sales data using Tableau and Microsoft Excel. The goal is to understand sales performance, identify sales trends, compare regional performance, and analyze profitable and loss-making areas through an interactive dashboard.

## Objectives

- Understand sales performance across categories
- Analyze sales trends over time
- Identify profitable and loss-making areas
- Compare regional performance
- Build an interactive dashboard

## Dataset

The dataset contains 400+ retail order records with the following fields:

- Order Date
- Category & Sub-Category
- Region
- Sales
- Profit
- Quantity

## Tools Used

- Tableau Public
- Microsoft Excel

## Analysis Performed

### Category Performance Analysis

Analyzed sales performance across different categories and sub-categories.

### Sales Trend Analysis

Analyzed sales trends over time using order date information.

### Profitability Analysis

Analyzed sales and profit data to identify profitable and loss-making areas.

### Regional Performance Analysis

Compared retail performance across different regions.

### Interactive Dashboard

Created an interactive dashboard to explore the retail sales data and support business decision-making.
