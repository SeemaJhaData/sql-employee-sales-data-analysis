# Retail Sales Performance Dashboard | Tableau

##  Project Overview

This project focuses on analyzing retail sales data to evaluate sales performance, profitability, regional trends, and product category performance using Tableau.

The project includes data analysis, interactive dashboard creation, KPI visualization, and business insights to understand overall retail performance.

##  Tools & Technologies

- Tableau
- Microsoft Excel
- Data Analysis
- Data Visualization
- Interactive Dashboards
- KPI Analysis
- Filters & Charts

##  Dataset

The dataset contains 400+ retail sales records with information related to:

- Sales
- Profit
- Region
- Product Category
- Product Performance
- Market Performance

##  Analysis Performed

- Analyzed overall sales and profit performance.
- Performed category-wise sales analysis.
- Performed region-wise performance analysis.
- Analyzed product profitability.
- Identified high-performing products and markets.
- Compared sales and profitability across different segments.

##  Dashboard Features

The Tableau dashboard includes:

- Interactive charts
- KPI indicators
- Filters
- Sales analysis
- Profit analysis
- Regional analysis
- Category-wise analysis
- Product performance visualization

##  Key Insights

The analysis was used to identify:

- High-performing product categories.
- High-performing regions and markets.
- Profitability patterns.
- Sales performance trends.
- Areas requiring further business attention.

##  Business Objective

The objective of this project is to transform retail sales data into meaningful visual insights that can help understand sales performance, profitability, regional trends, and product performance.
